# 简易模式与老人模式排版修复

应用保持现有字号，Android Activity 的 `fontScale` 固定为 `1.0`，WebView 的文字缩放固定为 `100%`。启动、字体配置变化和返回前台时均应用此规则，仅影响本应用；显示密度仍跟随设备配置，通过窄屏布局适配系统显示放大。

网页固定 `16px` 的 rem 基准，同时保留浏览器文字调整为 `100%`。充值抽屉固定客户信息、到账预览与核对按钮，仅表单滚动；收款渠道保持四列单行，选填且可取消。扣款抽屉固定客户、金额和底部操作，仅常用项目与说明滚动。常用项目采用三列网格，300px 及以下改为两列，长项目名最多显示两行。短屏键盘按键仍至少 44px，横屏采用左侧项目、右侧键盘。会员详情仅内容区域滚动，底部“额度充值”“消费扣款”固定在同一行。

Android 状态栏使用白色背景与深色文字，启动、字体配置变化、返回前台及重新获得焦点时恢复可见状态。原生窗口按实际 `systemBars`、刘海和输入法边距限制 WebView 的范围，兼容 Android 15 强制 edge-to-edge；固定按钮始终位于系统导航栏上方。原生网页取消重复的顶部占位，底部再保留 12px 操作间距；浏览器仍使用 CSS 安全区。输入文字说明时收起金额键盘，打开金额键盘前让文本输入框失焦。

头部品牌与“新客户”按钮保持单行。窄屏按可用宽度显示“会员管家”或“会员管家”，图标缩小，日期和状态显示为“11/02 · 离线”等简写；登记按钮字号保持 `16px`，触控高度至少 `44px`。搜索框高度收紧至 `48px`，保留顶部状态栏安全区。极窄屏或短屏允许头部随页面滚动。

主导航为“客户 / 流水 / 设置”。客户页共用最近来店、全部客户、低余额和欠款客户列表，行内直接扣款，档案中查看偏好、历史并充值。“今日小店收银简报”保留在“流水 → 收银简报”。姓名、手机号、尾号与流水关键词在输入变化、失焦和输入法提交后立即模糊搜索，简报视图隐藏搜索框。标准服务不自动打开键盘，改价时点击金额。

## Android 回归验证

使用 Java 21、Android SDK 35 和连接的测试设备，在项目根目录运行 `npm run build` 后执行：

```powershell
cd android
.\gradlew.bat connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.hairstudio.memberapp.FontScalingTest
```

`FontScalingTest` 检查启动与重建后的应用字号、模拟字体配置变化时 WebView 缩放复位、设备密度和语言保留，以及返回前台时文字缩放复位。新增系统栏深色文字与退出全屏的复位检查，以及 WebView 四边均位于系统栏和刘海安全范围内的检查。

真机验收步骤：

1. 开启手机简易模式/老人模式，将系统字体与显示大小调到最大，再启动新版 App。
2. 检查客户页四类筛选、负余额档案、欠款扣款确认框、还款充值、流水和设置页；文字不重叠，不出现横向溢出，底部导航不遮挡操作。欠款确认框应可滚动到知晓勾选框与确认按钮。
3. 使用长会员姓名和较大金额检查会员详情、新建会员、充值套餐、充值确认、扣款键盘和新增服务弹窗；滚动常用项目时扣款金额、键盘和确认按钮不移动，滚动充值表单时到账预览和核对按钮不移动。检查手势导航与三键导航，确认按键均在系统导航栏上方。编辑文字说明后打开金额键盘，系统输入法应收起。
4. 在充值或扣款表单中输入未提交的内容，切到系统设置修改字体大小，再返回 App；字号稳定，未提交内容保留。
5. 退出简易模式后再次打开 App，并检查状态栏时钟、网络、电量均清晰可见；检查横屏或短屏下的滚动与按钮显示。
6. 在服务与价格中保存赠送比例 12.5%，充值 19.99 元应自动赠送 2.50 元，并可手调；关闭赠送后套餐、表单和确认框均不显示赠送，到账等于实收。渠道默认不选，选择后再点取消；确认框打开期间更改规则后需再次核对。打开输入法时核对按钮应随可用窗口底部上移。
