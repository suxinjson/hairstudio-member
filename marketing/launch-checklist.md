# 发布前核对清单

## 产品和经营准备

- [ ] 发布批准完成；明确可售版本、发布日期、APK 签名与下载来源。
- [ ] 在线/离线方案各完成目标设备验收，写明型号范围、连接要求、离线期限和数据权威。
- [ ] 定义授权期限、功能范围、设备数、续费、升级、停服与退款条件。
- [ ] 评估数据迁移：可接受来源/格式、数量限制、映射、人工核对、报价和失败处理。未经专项验证不承诺通用旧系统迁移。
- [ ] 明确云主机、数据库、备份、恢复演练、客服时段、响应目标及故障处理责任。不要宣传零数据丢失、自动容灾或远程撤销离线设备。
- [ ] 准备服务合同/订单条款、隐私告知、数据处理职责、售后及争议处理流程；评估经营主体、税务和适用互联网服务资质。
- [ ] 所有截图、演示帐号、评价和案例有授权且去标识化；不得使用开发/验收数据冒充客户实绩。

## 渠道发布

- [ ] 闲鱼：在实际卖家账号中确认经营者身份、可选类目、服务/软件发布权限、交易和售后规则；只用平台订单与允许的沟通方式。
- [ ] 小红书：确认是“软件/工具商品”还是“软件服务”类目、入驻主体、资质、自动/平台内交付和店铺功能是否适用。电子资源规则要求工具类软件提供开发者授权或自身开发资质证明；若涉及经营性互联网信息服务，还须核对规则要求的对应许可。对实际 SaaS 类目不确定时先向平台书面咨询，不得错放类目。
- [ ] 小红书笔记、评论、直播、私信均不放外部联系方式、二维码、站外账号/链接或暗号，不引导站外交易；实际销售仅使用平台允许的交易功能。
- [ ] 发布日再次检查平台最新规则与商品类目要求。平台审核结果和规则执行会有变动，不能承诺“绝对不会违规”。
- [ ] 文案不夸大性能、适用范围、价格、兼容性、收益、安全、授权期限或售后；删除“国家级/最佳/第一”等绝对化用语和无证据的顾客评价、销量数字。

## 客户数据与安全

- [ ] 演示与宣传使用合成数据。客户发来真实会员名单、手机号、余额或支付记录时，先停止通过普通聊天传输并引导其不要发送。
- [ ] 仅收集交付所必需信息，告知目的、方式、范围、保存期限、共享对象及权利行使方式，并限制访问与留存时间。
- [ ] 不把客户数据用于广告案例、模型训练或转介绍；另有用途必须有合法依据和相应授权。
- [ ] 验证备份读回与恢复流程，明确离线本地账本、在线账本、手机副本和待同步操作之间的边界。

## 试点复盘指标

首批 5–10 家试点跟踪：询盘到演示比例、演示到成交比例、首次配置成功率、首次交易成功率、7/30 天活跃、退款/投诉原因、单店支持工时、迁移额外工时、毛利和续费意向。明确样本数量与时间，未实测前不写成宣传效果。
