## 一句话定位

**给发廊单店使用的会员、储值和收银工具：店里可按经营方式选择在线账本，或在支持的 Android 设备上使用独立离线账本。**

不要将本软件描述为多门店 SaaS、自动营销增长工具、支付通道、云端自动容灾方案，或保证提升营业额的服务。具体可用功能、期限、设备、联网条件、备份边界和售后范围，应以正式版本、实际订单及书面服务约定为准。

## 建议执行顺序

1. 先用合成数据制作截图/演示，访谈 10–20 家目标门店，记录现有记账流程、设备和最愿意付费解决的问题。此阶段只做调研，不收款、不发放授权。
2. 通过项目发布门槛并确定经营主体、隐私说明、售后流程、交付/退款条款、成本和最终价格。
3. 在平台商家后台确认适用类目与准入资格；类目不明确时先向平台客服核实，不要错放类目。
4. 小范围按单店试点，逐单记录安装成功率、问题类型、支持工时、退款原因与续费意愿，再调整套餐与价格。
5. 仅在平台允许的功能内成交与引导；不以暗号、二维码、个人联系方式或站外账号绕过平台交易限制。

规则链接和核对日期见各文档末尾；平台规则可能变化，发布当日须复核。
