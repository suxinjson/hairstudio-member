# 平台功能回归与上线验收

平台身份、授权和诊断已随 v2 候选通过全量回归。新账本验收（真实 PostgreSQL、容量、恢复、签名和手机）以 [实施台账](refactor-implementation.md) 和 [专项门槛](refactor-test-plan.md) 为准，当前没有生产发布结论。

## 自动化覆盖

新增 server/tests/platform.test.js 覆盖默认拒绝、身份隔离、门店创建、在线期限与离线小时数交集、授权版本冲突、事务内功能限制、停店、平台禁用用户、开发者权限、最后管理员保护、密码变更撤销会话、签名篡改/换设备/未知公钥、永久及按天许可、未配置签名密钥、离线激活/登录/退出/重启/到期和游标分页。

tests/diagnostics.test.js 覆盖采样、批量、队列上限和 DB 故障丢弃计数；tests/platform-client.test.js 覆盖平台令牌隔离、失效清理、旧请求丢弃及断网退出。平台禁用的店主不计入商家最后在用店主保护。原业务集成测试明确创建已获授权的测试门店；生产 createOwner 默认不授予许可，不以测试开关削弱运行时策略。原匿名读写预期更新为登录前隐藏账本、凭据丢失时拒绝记账并保留本机数据。

~~~sh
npm test
npm run build:web
npm run admin:build
~~~

默认集成环境使用 PGlite 和文件 SQLite，真实 PostgreSQL 多连接验收使用专用可丢弃数据库和同集群的管理员测试连接。候选回归计数及对应报告集中见 [实施台账](refactor-implementation.md#验证命令与当前证据)。隔离测试证据不替代 Docker、实际部署与手机验收。

## 上线功能验收

| 场景 | 预期 |
| --- | --- |
| 新安装未登录 | 隐藏会员、资金及主导航；显示在线登录/离线激活入口 |
| 无商业许可的旧店主 | 密码正确也不能进入业务；平台管理员仍可登录补授权 |
| 平台/商家互换令牌 | 都返回 401，不扩大租户范围 |
| 平台创建门店 | 店主/空账本原子创建，需另行授权；其他门店数据不变 |
| 网络授权到期、禁用门店/账号 | 下一次在线核验拒绝；不丢本机账本或待办 |
| 店主试图解除平台禁用 | 仍然拒绝登录，platform_disabled 不变 |
| 关闭某商业写入功能 | UI 按授权展示，直接调用 API 或语音绕过仍被拒绝 |
| 未配置签发私钥/受信公钥 | 签发/导入失败，不降级为无签名许可 |
| 授权码改期限、换设备 | 验签或绑定校验失败，原账本不被覆盖 |
| 离线永久/按天许可 | 无网络完成激活/本地登录；到期或退出后拒绝写入 |
| 跨门店换码、带云端待办切换 | 先拒绝并要求处理归属和待办 |
| 常见时间回拨 | 持久化水位阻止重启租期；原系统限制见运维文档 |
| 诊断队列满或数据库故障 | 诊断丢弃可观测；关键审计和业务保持同事务语义 |
| 并发管理编辑 | 陈旧 expectedVersion 返回 409，最后超级管理员不能同时撤销 |
| 升级 APK | 验证已有下载缓存复用、自动打开安装器和返回重试流程无回归 |

Android 真机必须另验：首次激活、Keystore 故障、断电/杀进程、时区与时间调整、设备标识稳定性、卸载/重装、备份迁移、后台恢复、网络切换、安装器返回。网页构建成功不能当作原生安装包或真机验证通过。

## 目标环境容量

准备去标识化的大小门店样本，分别测同店竞争和跨店吞吐。记录 CPU/RSS、连接池等待、活跃连接、锁等待、磁盘 IOPS、WAL、诊断丢弃数、业务吞吐及 p50/p95/p99。至少包含：小额充值/扣款、热点会员竞争、独立会员竞争、批量导入、平台翻页查日志、登录失败流量和语音外部服务超时。

在当前 v2 分别验证热点账户版本冲突、不同会员并发、分页/增量同步与 SQL 查询计划。数据集、负载、P95/P99 预算与故障门槛见专项测试计划。不能为了吞吐牺牲幂等、余额与审计一致性，也不能用 91 人空流水样本代替增长压测。

故障演练应覆盖 API 实例重启、数据库连接中断、主库切换、复制落后、密钥不可读、磁盘满、新库恢复换代、客户端离线超过期限后重连和旧代际待办阻断。记录实测 RPO/RTO、数据核对结果及回滚步骤，再决定是否启用更激进的集群或分库方案。
